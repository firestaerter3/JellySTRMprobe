Fast Start

Jellyfin probes a STRM file and refreshes its metadata on every playback, even when the streams are already known. That costs about 10 seconds per start. With this on, an item that already has a video stream starts without that step. Items that were never probed still get Jellyfin's normal probe on their first start.

Catch-up Mode

Automatically probe new STRM items in the selected libraries when they are added during library scans. Items are debounced (30 seconds) to batch-probe efficiently. Off by default: after a large sync this starts many probes at any time of day.
